# Django Blog Management System — Tech Insights

**Welcome to Tech Insights!**

This repository contains the source code for a real-world **Django Blog Management System** built using Python and Django.

The project demonstrates practical Django development, including models, templates, forms, authentication, CRUD operations, Django Admin, custom dashboards, search, categories, media uploads, static files, and deployment.

## Database Models

### Category

The `Category` model is used to organize blog posts into different categories.

### Blog

The `Blog` model stores information about each blog post, including:

- Title
- Slug
- Category
- Author
- Featured Image
- Short Description
- Blog Content
- Status
- Featured Status
- Created Date
- Updated Date
